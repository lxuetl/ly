# 几何条件引导的视频预测与风险修正实验

本仓库保存旧实验服务器在 2026-10-23 导出的代码及小型实验记录，用于备份、协作和后续复现。它是工作目录快照，不代表方法已取得有效提升；各实验的结论需要结合对应指标、配置和数据划分判断。

## 目录

- `server-snapshot/projects/`：Open-d4rt、OpenSTL、PredFormer、DMVFN 等项目的源代码、配置、文档，以及工作目录中的实验脚本和小型结果文件。
- `server-snapshot/experiments/`：旧机 `d4rt_training` 下符合导出规则的指标、配置、划分清单等。
- `server-snapshot/manifest.json`：已导出文件的相对路径、大小和 SHA-256 校验值。

## 快照边界

仅导出选定类型且单文件不超过 2 MiB 的文本文件。数据集、模型权重、视频图像、运行环境、缓存、原项目 Git 历史和符号链接不在此次导出范围内。数据与权重通过服务器迁移单独保存。上游项目自带的许可证保留在对应目录，使用及再分发请遵守各自许可证。

原代码可能引用 `/root/autodl-tmp` 和 `/root/autodl-fs` 等绝对路径。克隆仓库后需要安装相应依赖、准备数据和权重，并调整路径；此次上传未重新训练或验证模型效果。Manifest 校验针对文件字节内容，建议保留 LF 换行。

## 多人实验建议

每人使用独立分支；提交代码、配置和小型指标，注明基础提交、随机种子、数据划分与启动命令。大文件保存在单独的存储中，在实验记录中注明位置及校验值。不要提交访问令牌、服务器密码或私钥。
