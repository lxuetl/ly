# 历史筛选、局部重采样与两端联合门控：CPU 诊断

日期：2026-10-19。没有正式训练、参数拟合、阈值搜索或在线模型权重更新。

## 结论

**当前这套廉价可靠性规则没有改善最终预测，不应直接进入正式训练或替代 TAU。**

40 视频历史审查显示，末帧锚定的 LK 自洽检查与局部 NCC 重采样没有恢复正确对应关系；4 个冻结输出片段中，两端联合门控在相同实际修改量下，相比不筛选注入，MSE 和 LPIPS 都是 4/4 更差。

这否定的是下面这套具体规则，不是否定所有可靠性门控。严格的 D4RT 三方历史回放尚未完成，原因和已有非因果敏感性对照明确分开记录。

## 1. 范围与信息边界

- 历史审查：原有 manifest 的全部 40 个 evaluation 视频；复用验证数据，属于探索性诊断。
- 冻结输出：manifest 中前 4 个片段，按既定顺序选择，没有根据本轮效果挑选片段。
- 资源：服务器 0.5 核 CPU、2 GiB 内存，单线程、每个输出片段独立进程。
- 正常推断只使用历史 RGB、D4RT 历史 XYZ/UV/valid/confidence 和冻结轨迹预测器。决策函数没有读取 GT 坐标、GT 可见性或未来 RGB。
- 历史/未来 GT 仅用于完成决策后的诊断评测；它们不决定掩码、阈值、轨迹候选或修正方向。
- TAU 和轨迹预测器均冻结。4 个输出片段逐 tensor 验证 TAU 权重与启动前一致，参数没有梯度。

## 2. 实际实现

### 历史一致性筛选和重采样

从 D4RT 最后一帧位置出发，逐相邻历史帧向后做 LK，并检查每一步往返误差。局部重采样只在原 UV 的 3×3 像素邻域中搜索，匹配最后历史帧的 5×5 灰度外观模板。

预先固定规则：LK 往返误差 ≤1 像素，重采样位置距 LK 位置 ≤2 像素，NCC ≥0.6，模板标准差 >0.02；局部位置更新要求 NCC 提高 >0.03。无纹理、无效或证据不足就拒绝。没有根据验证结果重新放宽阈值。

注意：末帧锚点本身可能已经漂移；往返自洽不等于对应了正确的点身份。这是本方案的重要未解决假设。

### 未来端点启发式门控

用独立的 RGB 历史 8→8 回放比较保持最后位置与恒速，在历史内部选误差较小的简单模型；要求对应 horizon 的回放误差中位数 ≤2 像素，且当前预测端点与该简单模型的分歧 ≤2 像素。

这是跨点汇总的历史启发式，不是经过独立校准的逐点未来正确概率，也不是收益评分器。不存在人工偏好、TTT 或 TTPO。

## 3. 40 视频历史结果

每项先在视频内计算，再对 40 个视频等权平均。位置误差单位为 128 分辨率图像上的像素。

| 指标 | 结果 |
|---|---:|
| 历史样本保留比例 | 39.01% |
| 端点启发式通过比例 | 28.70% |
| 原始历史位置误差，所有有效标注样本 | 2.138 |
| 原始位置误差，仅筛选保留的同一批样本 | 3.103 |
| 重采样后位置误差，同一批保留样本 | 3.394 |
| 原始 RGB 采样 MAE，同一批保留样本 | 0.07826 |
| 重采样后 RGB 采样 MAE，同一批保留样本 | 0.09170 |

局部重采样后的坐标误差在 40/40 个视频中变差；RGB 采样误差仅在 5/40 个视频中改善。保留集合比全集的误差更大，但二者是不同子集，不能把差值解释成坐标修改的因果效应；同一保留集合的原坐标/新坐标比较才隔离了重采样作用。

因此 NCC 分数提升不能被解释成恢复了真实对应关系。由这些结果推测，末帧锚点错误、纹理歧义及真实外观随时间变化，都可能导致“外观更相似但身份更错误”；尚未逐项分离这些原因。

## 4. 历史回放：严格结果与非因果结果分开

### 严格 RGB-only 回放，已完成

只在历史前 8 帧中产生角点、跟踪状态和运动外推，冻结预测后才读取后 8 帧。后段连续且通过循环检查的 LK 轨迹作为观测参考，**不是 GT**。

| 方法 | 相对 LK 观测参考的平均位置误差 |
|---|---:|
| 保持最后位置 | 4.994 px |
| 恒速外推 | 3.976 px |

恒速在 25/40 个视频中更好。结果仅适用于存活且可跟踪的角点，不能代表遮挡点，也不能直接等同于 D4RT 查询点的真实轨迹精度。

### 缓存切片三方敏感性，已完成但非因果

完整 16 帧 D4RT 历史结果切出前 8 帧，不能保证前缀估计没有接触后 8 帧。因此下面只作为明确标注的敏感性分析，**没有用于门控选择或校准**。

| 方法 | 对历史后段 GT 的 EPE |
|---|---:|
| 保持最后位置 | 6.560 px |
| 恒速外推 | 5.227 px |
| 冻结轨迹预测器 | 6.010 px |

此外预测器的 8 帧输入与原来 16 帧训练输入存在长度/时间归一化分布差异。因此不能据此宣称严格部署条件下预测器不如恒速。

### 严格 D4RT 三方回放，未完成

未找到独立前缀 D4RT 缓存。现有 D4RT 检查点约 13 GB，模型为大型 ViT，当前 2 GiB 实例不足以直接按现有加载流程重算。没有冒险加载，也没有用伪 XYZ、GT XYZ 或完整历史切片充当严格前缀输入。

完成此项需要独立前缀 D4RT XYZ/UV/valid/confidence；可以由 GPU 实例或具有足够内存的 CPU 实例生成。还需要明确 8 帧输入分布偏移，或在具备更长观测序列时做同长度滚动回放。

## 5. 冻结 TAU 最终输出：4 片段

比较 keep/TAU、原始历史注入、仅历史筛选、历史筛选加重采样、仅端点门控、两端联合门控。历史筛选/重采样对照共享同一筛选掩码，以隔离坐标更新作用。

所有方法都只做一轮 hidden/skip 修正；特征步长 0.002、元素上限 0.05，输出平均 L1 上限 0.002、单像素上限 0.03。每片段再向下匹配各个非零修正分支的实际 RGB 修改量，不放大修改；若无支持则保持 keep。4 个片段本轮均存在非零支持。

下表为实际修改量匹配后的均值，指标均越低越好。平均实际 RGB 修改量约 0.0003886。

| 方法 | MSE | LPIPS | 时序误差 |
|---|---:|---:|---:|
| 原 TAU / keep | 0.00563189 | 0.189216 | 0.0192735 |
| 原始历史注入 | 0.00562781 | 0.189508 | 0.0192812 |
| 仅历史筛选 | 0.00562912 | 0.189598 | 0.0192876 |
| 历史筛选＋局部重采样 | 0.00562853 | 0.189661 | 0.0192873 |
| 仅端点门控 | 0.00562879 | 0.189546 | 0.0193083 |
| 两端联合门控 | 0.00563034 | 0.189801 | 0.0193149 |

联合门控相对原始注入，MSE 和 LPIPS 在 4/4 个片段中都变差；相对原 TAU，MSE 有 3/4 改善，但 LPIPS 为 4/4 变差。因此没有兑现多指标收益，不能因为修改更少或 MSE 均值略低于 TAU 就宣布成功。原始未匹配预算结果也保留在 JSON 中，避免只展示有利对照。

## 6. 下一步边界

1. 不进入正式训练，不解冻 TAU，不把当前门控部署为默认路径，也不通过放宽阈值避免 keep。
2. 历史侧下一项可做的低成本诊断，是用最初给定的查询位置锚定身份，比较首帧向前跟踪、末帧向后跟踪及二者的身份一致性。它是待验证方案，本轮没有实现，更不能宣称它必然解决遮挡或重识别。
3. 严格三方预测器回放依赖独立前缀 D4RT 缓存，不能用当前非因果敏感性结果替代。
4. 若以后重新设计门控，需要在独立开发/校准视频上验证“代理可靠性→最终修改收益”的关系，并在相同覆盖率、实际修改量下比较简单门控和随机门控。当前结果不支持直接训练更大的评分器。
