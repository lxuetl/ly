# CaPSR v3 低成本几何反事实实验报告

## 实验协议

- 冻结视频主干、未来轨迹预测器和 CaPSR v3 checkpoint；没有训练或 D4RT 重计算。
- 测试集：199 clips，来自 31 个原始 source sequences；逐域为 ADT、Dynamic Scene、PointOdyssey mini、PStudio mini 和 PointOdyssey-50。
- checkpoint：`capsr_v3_object_20260825/visibility000/best.pt`，epoch 19。
- 通过 Codex 历史补丁恢复与 checkpoint 对应的 v3 前向：固定 cycle radius/tolerance，并保留 v3 的双重 cycle/occlusion 置信度施加。当前 v4 源码没有被覆盖。
- 条件：正确几何、无修正、camera-only、object-only、时间反序、随机时间置乱、全局跨视频打乱、同域跨视频打乱、四档 UV 噪声、四档 XYZ 噪声、四档稀疏点 dropout。
- 统计：5000 次 paired bootstrap；按原始 source sequence 聚类并等权重重采样，避免把同一视频的多个 clip 当成独立样本。
- 同域跨视频条件只在存在至少两个原始视频的数据域上计算，共 177 clips、29 个 source sequences；`po_mini` 与 `pstudio_mini` 因各自只有一个原始测试视频而排除。

## v3 复现验收

| 指标 | 正确几何 v3 |
|---|---:|
| MSE ↓ | 0.009602 |
| PSNR ↑ | 20.176 dB |
| LPIPS ↓ | 0.177642 |
| Temporal MAE ↓ | 0.021871 |
| Dynamic MSE ↓ | 0.033656 |

这些数值与此前 v3 报告一致，说明恢复的 v3 前向与 checkpoint 对应正确。

## 结论

### 1. “视频对应的几何”确实有用，但主要体现在像素与动态区域保真度

同域跨视频打乱后：

- MSE 从 0.009602 退化到 0.010836，约退化 12.9%；序列级 95% CI 全部大于 0。
- Dynamic MSE 从 0.033656 退化到 0.037211，约退化 10.6%；95% CI 为 +0.002458～+0.006924。
- 29 个可比较原始序列中，20 个序列 MSE 变差，25 个序列 Dynamic MSE 变差。

这支持一个有限但重要的因果结论：**CaPSR 并非只使用与视频无关的几何统计量，几何和视频的对应关系对像素/动态保真度有显著作用。**

但 LPIPS 和 Temporal 的跨视频退化置信区间跨 0，不能声称正确几何在所有维度均显著更好。

### 2. 模型没有充分利用未来几何的时间顺序

- 反序对 MSE、LPIPS、Temporal 和 Dynamic MSE 均无显著影响。
- 随机 horizon permutation 对 MSE、LPIPS、Dynamic MSE 无显著影响，只让 Temporal MAE 小幅且显著退化。

因此当前模型主要利用全局/聚合的几何路径信息，而没有强烈依赖“第 t 步几何必须对应第 t 帧”的时序关系。论文不能宣称已经学会精确的未来几何时序控制。

### 3. 精确几何不是当前模型的最优输入：存在明显过度修正

UV 噪声越大，整体 MSE 和 LPIPS 反而越好：

- UV noise 0.05：MSE 改善约 9.2%，LPIPS 改善约 26.5%；两项的序列级 CI 均显著。
- 但 Dynamic MSE 从 0.033656 上升到 0.034245，且 Temporal 的序列等权结果显著变差。

这不是“噪声让几何更准确”，而是噪声削弱/平滑了几何修改，使模型减少高频或过强修正。当前精确 UV 被使用得过于激进。

XYZ 噪声影响较小，但 1%～20% 噪声同样轻微改善 MSE/LPIPS，同时持续损害 Temporal，说明 XYZ 分支也存在敏感度/校准问题。

### 4. 稀疏点存在冗余，适度 dropout 像一种推理期正则化

- 50%～75% dropout 显著改善 LPIPS 和 Temporal；整体 MSE 的改善因跨序列异质性而未达到显著。
- 90% dropout 开始显著损害 Dynamic MSE（95% CI +0.000393～+0.002604）。

说明当前 128 点并非越多越好：许多点会重复或冲突地扩大几何修改，但动态区域仍需要一个最低点密度。

### 5. 路径证据再次确认 Camera 主导

- Base-only MSE 为 0.044791；Camera-only 已降到 0.013999。
- Object-only 为 0.043942，几乎等于 Base-only。
- Full v3 为 0.009602，显著优于 Camera-only；但该差异同时包含 Object 和 Synthesis，不能全部归因于 Object。

Camera-only/Object-only 是固定 checkpoint 的推理反事实，不等价于各路径独立重新训练后的能力。

## 对论文主张的影响

现在可以写：

> 在 source-sequence clustered paired bootstrap 下，将几何替换为同域其他视频的几何会显著损害 MSE 与动态区域 MSE，说明模型利用了视频—几何对齐关系。

暂时不能写：

- 精确几何优于带噪/稀疏几何；
- 模型充分利用未来轨迹的时间顺序；
- 所有感知和时序指标都从正确几何中获益；
- Object 分支单独贡献很强。

## 下一步建议

不要直接继续堆新模块。下一步优先解决几何权限校准：

1. 将当前人为 noise/dropout 效果转化为可解释的 **confidence-aware point selection**。
2. 在验证集选择点保留率或每点温度，不在测试集据此调参。
3. 对 UV correction 使用低通/局部一致性约束，避免高频点级流直接扩大像素修正。
4. 增加显式的 horizon-conditioned trajectory-to-warp 映射，并用时间置乱对比损失迫使模型识别几何顺序。
5. 新结构必须同时报告 MSE、LPIPS、Temporal、Dynamic MSE，防止用牺牲动态真实性换取平滑指标。
